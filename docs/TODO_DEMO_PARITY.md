# کارهای باقی‌مانده: تطبیق با دموی NextMerce (برای انجام مشترک)

وضعیت بعد از دریافت فایل‌های mhtml دمو:
- ساختار و محتوای صفحه‌ها بررسی و هم‌ساختار شد: صفحه‌ی اصلی، فروشگاه، سبد، تسویه‌حساب، ورود، ثبت‌نام، تماس، علاقه‌مندی‌ها، حساب من، خطا، موفقیت ایمیل.
- پالت رنگ (blue، dark، gray، ...) با دمو یکی است؛ فونت فارسی (وزیرمتن) جایگزین فونت لاتین دمو شده است.

## هنوز انجام نشده
1. صفحه‌ی جزئیات محصول (`/shop-details`): فایل دمو ارسال نشده است. اسکرین‌شات یا mhtml لازم است.
2. تطبیق بصری دقیق (فاصله‌ها، سایه‌ها، اندازه‌ی فونت‌ها) با رندر واقعی مرورگر: فقط با مقایسه‌ی اسکرین‌شات‌ها در دو سمت ممکن است.
3. دکمه‌های Google/Github در ورود و ثبت‌نام: تصمیم گرفته شد فعلاً نباشد.
4. تب «دانلودها» در حساب من (فقط کالای دیجیتال): تصمیم گرفته شد فعلاً نباشد.
5. صفحه‌های وبلاگ: هنوز متن Lorem ipsum دارند (از منو مخفی‌اند).
6. اجرای `next build` و `npm run lint` روی سیستم کاربر.
