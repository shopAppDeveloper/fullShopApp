# کارهای باقی‌مانده: تطبیق با دموی NextMerce (برای انجام مشترک)

وضعیت: بررسی نشده، چون ابزار خودکار به این صفحه‌ها دسترسی نداشت یا فقط ساختار متنی در دسترس بود.

1. صفحه‌ی جزئیات محصول: https://demo.nextmerce.com/shop-details (مسدود بود)
2. حساب من: https://demo.nextmerce.com/my-account (مسدود بود)
3. تطبیق بصری همه‌ی صفحه‌ها (رنگ، فونت، فاصله‌ها، سایه‌ها، ریسپانسیو): فقط با اسکرین‌شات یا HTML ذخیره‌شده‌ی دمو ممکن است.
4. صفحه‌ی ورود: دکمه‌های Google/Github در دمو هست و در پروژه‌ی ما نیست (نیاز به تصمیم و بک‌اند).
5. فیلتر رنگ در فروشگاه: نیازمند داده‌ی ویژگی رنگ در محصولات.
6. صفحه‌های وبلاگ: هنوز متن Lorem ipsum دارند (از منو مخفی‌اند).
7. اجرای `next build` و `npm run lint` روی سیستم کاربر (در محیط ما بسته‌های npm نصب نمی‌شد).
